# ClipForge update channel

The ClipForge app downloads its updates from this folder. Every file is checked against ClipForge's signature and SHA-256 before anything is installed.

Current version: **2.0.11**

- Fixed: narrated videos could show in-game phone messages, menus, shop screens or the map under a line that had nothing to do with them. These screens are now left out, unless the line asks for a phone, menu or map.
