# ClipForge update channel

The ClipForge app downloads its updates from this folder. Every file is checked against ClipForge's signature and SHA-256 before anything is installed.

Current version: **1.8.3**

- Fixed: an AI script could come out far too short (a few sentences) when the quality fixes didn't fully succeed. A too-short version is never chosen now.
- Your quoted ending ("End with …") is always said.
