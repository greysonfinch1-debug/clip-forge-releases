# ClipForge update channel

The ClipForge app downloads its updates from this folder. Every file is checked against ClipForge's signature and SHA-256 before anything is installed.

Current version: **1.2.8**

- **Preview builds automatically:** when you open **5 · Edit & Captions** and the edit hasn't been built yet, ClipForge builds it straight away (voice, captions and the preview video) and plays it. You no longer need to know to click **Build edit**.
- **Picks up where you left off:** ClipForge reopens your last project when it starts, including after an update restart, and goes to the page you'd reached.
- If no project is open, page 5 now says so instead of showing an empty area.
