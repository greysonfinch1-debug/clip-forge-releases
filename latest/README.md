# ClipForge update channel

The ClipForge app downloads its updates from this folder. Every file is checked against ClipForge's signature and SHA-256 before anything is installed.

Current version: **2.0.8**

- **No more gameplay without a voice:** every clip now ends about a second after its narration or the last spoken words. A video made from gameplay without commentary used to play 2–5 seconds of silent footage after each line.
- **Hybrid videos only use stream moments where someone talks.** A moment without speech is left out instead of playing with no script.
- **Gameplay fills the whole screen:** without a webcam, the picture is now a full-height crop that follows the action. Before, the game sat in a band with blurry copies above and below. You can still choose "blur-fill" in Settings if you want the whole frame.
