# ClipForge update channel

The ClipForge app downloads its updates from this folder. Every file is checked against ClipForge's signature and SHA-256 before anything is installed.

Current version: **1.2.3**

- **About & Updates** shows when ClipForge last checked for updates and which version you're on.
- The update source label now reads "Update source (GitHub)".
- This is the first update delivered automatically through the new update channel, with no download or installer needed.
