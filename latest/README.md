# ClipForge update channel

The ClipForge app downloads its updates from this folder. Every file is checked against ClipForge's signature and SHA-256 before anything is installed.

Current version: **1.5.1**

- No more double screen: streams with a big webcam get one full-screen picture centred on the person.
- Gameplay fills more of the screen (about 60 % of the height instead of 46 %).
- Narrated videos open with a hook, explain each point clearly (numbered tips), end with a last piece of advice and a short "Follow for more."
- Swear words are masked in the captions (the audio isn't changed).
