# ClipForge update channel

The ClipForge app downloads its updates from this folder. Every file is checked against ClipForge's signature and SHA-256 before anything is installed.

Current version: **1.4.1**

- When the prompt names the footage to use ("use the cartoon footage", "with my Minecraft gameplay"), ClipForge now really uses that footage, even when there's little of it (it repeats it rather than switching to other videos, and step 2 says the library is small). "Calm footage" and similar describe the mood, not which video.
