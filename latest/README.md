# ClipForge update channel

The ClipForge app downloads its updates from this folder. Every file is checked against ClipForge's signature and SHA-256 before anything is installed.

Current version: **1.6.4**

- **Hooks are short and grab attention.** The AI writes several hooks and the strongest is used. A hook you write yourself in quotes is still used exactly.
- **Scripts sound spoken, not written:** short sentences, contractions, no filler or jammed-together nouns.
- **Channel intros and promos are written as promos**, not as fact lists.
- **The voice varies its delivery:** a punchier hook, changing pace between points, a slower final point and a lively ending.
- **Uses a bigger AI model for scripts** if you've downloaded one (for example `ollama pull qwen2.5:14b-instruct`).
- "GTA" is read as "G T A".
