# ClipForge update channel

The ClipForge app downloads its updates from this folder. Every file is checked against ClipForge's signature and SHA-256 before anything is installed.

Current version: **2.0.12**

- **Smoother narration:** much shorter pauses between lines, no long stop after a colon ("One: …"), and the voice's own little breaks inside a sentence are shortened. On a 6-line script the pauses went from 5.1 s to 2.2 s in total, and the longest from 0.79 s to 0.51 s.
- The video now ends a short breath after the last word instead of cutting it close.
