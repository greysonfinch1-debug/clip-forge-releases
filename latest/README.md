# ClipForge update channel

The ClipForge app downloads its updates from this folder. Every file is checked against ClipForge's signature and SHA-256 before anything is installed.

Current version: **2.0.0**

- **Topic ideas:** a new "Topic ideas…" button suggests Short ideas, scores them, checks each one against real sources, skips what you've already made, and fills the prompt with one click.
- **A bigger prompt box** that grows as you type, shows a word count and never loses your prompt ("Restore my last prompt").
- **Works reliably with Gemini and other online AI:** rate limits and hiccups are retried automatically, and a bad key or model name gives a clear message.
- **Settings are safer:** they survive a damaged file, wrong values are fixed automatically, and there's a new Reset to defaults button.
- **System Check really tests things now:** it asks your AI model a question and voices a test sentence.
- **Safety checks between steps:** a line with no audio is re-voiced or reported instead of leaving a silent gap.
- **Everything from 1.7 to 1.8:** the rebuilt script writer, the more natural voice, and never blocking a video.
