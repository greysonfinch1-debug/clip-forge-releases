# ClipForge update channel

The ClipForge app downloads its updates from this folder. Every file is checked against ClipForge's signature and SHA-256 before anything is installed.

Current version: **2.0.7**

- **No more long clips without narration:** in hybrid videos, each real moment from the stream now plays for at most 6 seconds, cut around its best part. A moment used to run as long as 19 seconds.
- **Stronger hooks:** a hook you write in your prompt now competes with 6 hooks written by the AI, and the strongest one is used. To keep yours word for word, write "use this hook exactly".
- **Better scripts from a detailed prompt:** the tips and facts you write in your prompt now count as verified, so the AI plans the video around them. Before, Gemini treated them as unconfirmed rumours and wrote without a plan.
