# ClipForge update channel

The ClipForge app downloads its updates from this folder. Every file is checked against ClipForge's signature and SHA-256 before anything is installed.

Current version: **1.2.4**

- **Faster updates:** ClipForge now sees a new update the moment it's published. Before, GitHub's file cache could delay it by several minutes.
- **Checks on every open:** ClipForge checks for updates each time it opens. The 20-minute wait is gone.
