# ClipForge update channel

The ClipForge app downloads its updates from this folder. Every file is checked against ClipForge's signature and SHA-256 before anything is installed.

Current version: **1.8.1**

- **When a script falls short, ClipForge fixes it:** first the exact sentences that are wrong, then bigger rewrites, up to 5 rounds.
- **It never stops you making the video.** If the script still isn't perfect, the best version is used, and you can edit any line in Script & Voice.
- **List-style scripts** ("#1… #2…") are turned into normal sentences.
